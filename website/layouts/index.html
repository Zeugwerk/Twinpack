The package manager for TwinCAT libraries

Find, install and update PLC libraries from TwinCAT XAE, Visual Studio or the command line. Pin versions in your repository and restore them anywhere, including your CI server.

Free and open source. Browse all packages

Get started in three steps

Twinpack works like NuGet or npm, built for PLC libraries.

Download the installer. It sets up the IDE extension for TcXaeShell and Visual Studio and the twinpack command line tool.

Download Twinpack Read the quickstart

Search the catalog on this site, in the IDE (right-click References, then Twinpack Catalog) or from the command line:

twinpack search --search-term ZCore

Add the package to your PLC project. Twinpack downloads it with all dependencies and installs it. Omit --version to get the latest.

twinpack add --package ZCore --version 1.2.19.0

Every package page on this site has a ready-to-copy command.

The versions you use are stored in .Zeugwerk/config.json next to your solution. On a fresh checkout or a build server one command installs them all:

twinpack restore

Why Twinpack

In your IDE and on the command line

Browse and install from TcXaeShell or Visual Studio, and script the same actions in CI with the twinpack CLI.

Reproducible builds

Pin exact versions, branches and configurations in a config file. Everyone, and every build server, gets the same libraries.

Three package sources

The Twinpack server, your own NuGet server for private libraries, and the Beckhoff library repository, all in one catalog.

Browse from inside TwinCAT

Right-click the References node of a PLC project and open the Twinpack catalog. Search, read the package details, pick a version and add it with all of its dependencies.

Already know what you need? Use the search on this page and copy the command.

Publish your library

Share your TwinCAT library with the community. Pick what fits your workflow:

Twinpack Registry

Open a pull request that adds your GitHub repository. Libraries from your GitHub releases are published automatically. Twinpack-Registry

From CI

Push from your pipeline with twinpack push or the Twinpack GitHub action. You need a free Zeugwerk account.

From the IDE

Right-click the PLC project, choose Twinpack, then Publish. Set distributor and version and upload.
